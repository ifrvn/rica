# Rica 控制台功能规划

控制台面向角色管理员、审批员和审计员。首个版本让操作者在网页内完成「创建角色 → 配置身份与模拟账号 → 发起一次模拟 → 审批 → 查看回执」。登录账号仍由现有 CLI 初始化，实际执行仍由独立执行器负责。

依据[开发路线图](roadmap.md)、[管理 API](management-api.md)与[插件架构计划](plugin-architecture-refactor.md)。

## 1. 当前能力

| 已有界面 | 当前边界 |
| --- | --- |
| 服务与运行 | 查看服务就绪、角色积压、运行轨迹、回执、隔离出箱和对账状态。 |
| 登录与成员 | 使用本地密码或 Passkey 登录。角色管理员在网页授予和撤销现有账号的权限。 |
| 角色与审批 | 创建和配置角色、身份、账号。在模拟和本机连接器队列查看提案、审批和结果。 |
| 知识与成长 | 浏览脱敏记忆与来源，配置限用途授权。按身份查看成长记录与联系边界。 |
| 运行配置与指标 | 管理模拟计划及承诺，查询近期预算、漂移和评测指标。 |

## 2. 信息架构

| 一级入口 | 主要内容 | 首次交付 |
| --- | --- | --- |
| 工作台 | 当前角色的状态、待审批或待处理事项、最近运行。按当前用户权限提供可执行入口。 | C1 |
| 角色与身份 | 角色列表、核心配置、身份、平台账号。角色状态和暂停入口固定在角色页。 | C1 |
| 审批 | 模拟提案与本机连接器提案分栏，查看目标、正文、证据风险、决定和结果。 | C1 模拟，C2 本机连接器 |
| 运行 | 最近运行、阶段与回执，后续增加积压、隔离事件与对账。 | C1 运行与回执，C2 异常处置 |
| 插件 | 查看部署的插件、进程状态和当前角色的连接器绑定。 | C2 |
| 知识与成长 | 记忆与来源、授权、目标、反思、观点和精力。身份在模块内固定。 | C3 |
| 权限与审计 | 角色成员、权限分配、操作记录。个人会话与 Passkey 从顶部账号菜单进入。 | C2 审计，C3 成员 |

顶部保留角色选择、服务状态和个人菜单。默认落到当前用户能完成的首个任务。首次登录且没有角色时，有创建权限的用户可直接进入创建流程，其他用户看到等待授权状态。待交付的导航随功能上线。切换角色时清除上一个角色的详情、列表和待提交操作，忽略返回较晚的请求。列表入口和所选详情支持刷新及浏览器返回。链接保存角色、页面及详情 ID，草稿和审批理由留在当前操作中。运行列表的筛选条件也保存在链接中。

## 3. 分阶段交付

### C1 模拟操作闭环

已接入角色与身份工作区、模拟账号登记、模拟发起、审批待办、运行分页与回执详情。控制台为每次模拟创建独立公开会话，沿用正常审批和独立执行器。隔离环境已用管理员和独立审批员在浏览器验证发起、批准和回执。角色、审批提案及运行详情支持直达链接。刷新与浏览器前进、返回会恢复角色和所选详情。隔离浏览器夹具已验证登录后恢复、越权拦截，以及切换角色后忽略迟到响应。

- 控制台骨架与权限导航。会话读取返回当前主体是否可创建角色，角色上下文返回自己的权限集合。角色列表沿用服务端分页。
- 角色与身份配置。创建和编辑核心、创建身份、绑定模拟账号，显示暂停原因和当前配置版本。启用、暂停和恢复沿用现有控制命令。
- 「运行一次模拟」引导。管理员选择包含身份的模拟账号，输入模拟消息后启动运行。宿主为每次运行建立独立公开模拟会话，写入事件和事务出箱，随后交给正常 Worker、审批与执行链路。模拟始终限定在模拟账号和模拟适配器。
- 复用现有审批交互，补最近运行列表和回执详情。审批决定与执行结果分别展示。管理员和审计员按权限查看回放；审批员仅查看其审批页有权读取的内容和结果摘要。

**验收** 从独立空库完成账号初始化后，ADMIN 能在网页创建角色、身份和模拟账号，启动一次模拟并获得可点击的运行记录。独立 REVIEWER 能看到待办并批准。执行器生成唯一模拟回执，ADMIN 可从运行列表进入回放。双身份验收确认账号和审批内容始终对应所选角色与身份。全过程无需手填资源 UUID。

### C2 日常运行与异常处置（已验收）

首批已接入角色积压与隔离出箱。ADMIN 可按事件代次填写理由恢复，AUDITOR 可查看事件和关联运行。隔离浏览器已验证版本冲突后的重新核对、理由保留和恢复后计数更新。待对账的模拟运行详情已提供管理员结案入口，提交以封存账本给出的结论为准。浏览器已验证等待证据、版本冲突后保留理由和结案后的状态刷新。审计页支持角色级操作记录和运行相关记录，管理员及审计员可从运行详情进入。隔离浏览器已验证审计员分页与返回、审批员直达权限和窄屏详情。本机连接器的审批队列支持按状态分页、直达详情、查看回执与管理员结案。列表只返回元数据，批准后显示待发送。模拟运行已支持按状态、身份、账号和 UTC 日期组合筛选，条件随直达链接恢复。运行详情按入站、草稿、审批、执行许可和模拟回执展示脱敏轨迹。积压可直接筛出待对账运行。插件页可进入角色的平台账号，管理员可选择身份并登记本机连接器账号。新绑定默认暂停，恢复时只向部署配置的回环地址核验读取权限和 Agent ID。账号页显示最后一次成功读取、最近错误码和允许下次读取的时间。管理员可查看最近事件和按账号筛选的提案，审计员只查看运行状态。

- 工作台补角色级积压与明确的处理入口。运行列表支持状态、身份、账号和时间筛选，详情串联入站、草稿、审批、许可及回执，正文按现有授权投影展示。
- 将隔离 Outbox、模拟对账、审计和本机连接器事件接到控制台。补本机连接器提案的角色级分页与状态筛选，以审批队列替代手填 ID。
- 上线「插件」页，提供脱敏状态和当前角色的连接器绑定。配置与执行权限按插件专项规划分期。
- 暂停、撤销、恢复和对账各自显示作用域与后果。未知结果只提供对应的对账或结案入口。隔离事件恢复使用当前代次和理由。

**验收** 从积压进入对应记录，ADMIN 可在权限范围内完成一次隔离恢复和一次对账，AUDITOR 可查看关联记录，越权用户直接访问详情仍被 API 拒绝。管理员可在网页找到本机连接器的待审提案和结果状态。隔离夹具验证重复提交、暂停和未知结果处理。

验收结果已通过。浏览器验证插件状态分开显示、账号登记、核验失败后保留理由、账号级提案入口、积压直达、隔离恢复、账本结案和窄屏使用。独立 PostgreSQL 18 与 Redis 8 验证核验失败时保持暂停、成功恢复幂等、暂停后无法取得新发送许可、跨角色查询拒绝、诊断脱敏及 Worker 报告过期。验证中的连接器写入仅发生在协议夹具的显式发送测试中。

### C3 配置、知识与审计（已验收）

- 角色成员列表和授权编辑，明确 ADMIN、REVIEWER、AUDITOR、OPERATOR 在当前角色的有效权限。创建本地账号继续走 CLI。保留至少一名 ADMIN 的限制。
- 记忆按身份、作用域和状态浏览元数据，关联来源、修订和授权。授权表单按用途限定可选的账号、会话与联系人，并展示期限。纠错、撤销和观点恢复沿用版本检查与审计。
- 身份详情增加目标、反思、观点、精力和关系边界。先接现有可查询详情；需要浏览的观点和联系人补作用域内分页。计划和承诺放在角色的运行配置区。
- 工作台增加近期预算、漂移与评测摘要。指标保留角色、时间范围和模拟标识。

**验收通过** ADMIN 在网页授予角色权限，最后一名 ADMIN 的撤销被拒绝并保留理由。记忆授权按身份和账号筛选私聊会话，联系人从会话绑定确定。浏览器已验证限期授权、撤销、记忆修订、观点恢复、联系边界、计划登记、由模拟回执创建承诺，以及审计员的只读来源追踪。模拟指标按角色和 UTC 日期查询，默认显示最近 14 个完整 UTC 日。窄屏可完成核心流程。

隔离 PostgreSQL 18 和 Redis 8 验证成员分页、越权、私聊绑定错配、已撤销授权、版本冲突和脱敏范围。审计员可看记忆元数据、来源和操作记录，授权列表及写入由管理员操作。本地账号继续通过 CLI 创建。

### 后续候选

管理员账号生命周期、自定义角色权限和批量操作各自立项。插件配置、启停和安装流程见下一节。

## 4. 插件专项

插件实现随 Rica 部署。模拟适配器由启动允许列表装配，内置外部模型和 Newbi 由插件中心登记安装、启用和停用。角色内的账号绑定与部署级插件生命周期分别管理。长驻进程每 5 秒更新报告，20 秒无报告后显示未知。同类进程展示最近一份报告。单次连接器报告保留 1 小时，完成表示命令已结束。[插件架构计划](plugin-architecture-refactor.md)

| 阶段 | 控制台功能 | 操作边界 |
| --- | --- | --- |
| C1 配置入口 | 创建模拟账号时只提供当前部署启用的模拟适配器。若对应能力不可用，说明原因并保留用户填写的配置。 | 优先复用 API 进程已装配的允许列表。模拟触发仍只接受模拟账号。 |
| C2 插件页 | 查看插件 ID、实现版本、契约版本、能力、所属进程及最近脱敏诊断。进入详情查看当前角色的账号绑定，复用平台账号的暂停与恢复规则。 | 状态来自对应进程的报告，API 进程自身就绪不代表 Worker 就绪。缺少报告显示「未知」，单次连接器退出后显示最近结果。角色 ADMIN 只能管理本角色的绑定。 |
| C2 连接器配置 | 部署操作者在 Newbi 插件卡保存本机 Agent API 地址和密钥。角色管理员到平台账号池登记账号并关联身份，随后核验连接。 | 配置响应和变更日志省略凭据。身份核验或授权失败时保留暂停状态。读取与发送分别检查。 |
| 内置插件管理 | 部署操作者安装、启用或停用内置 Newbi 和外部模型，查看各插件的版本和配置入口。 | 控制台安装登记随部署交付的固定版本。受信发布源、版本升级与卸载另行交付。 |

内置插件配置由具有创建角色权限的本地部署操作者管理。模型选择影响该部署全部角色的公开模拟草稿，保存或停用后从下一次草稿任务生效。API、认知 Worker 和 Newbi 命令使用同一个受保护的设置目录。默认按部署数据库的主机和库名定位，进程使用不同数据库地址或系统账号时，显式共享 `RICA_MODEL_SETTINGS_DIR`。Newbi 执行和读取继续使用各自的数据库角色。旧部署在首次登记时沿用已配置的模型和 Newbi 凭据，后续以保存的插件状态为准。

停用 Newbi 会阻止新客户端取用凭据，也会阻止已打开客户端发出后续请求。已经发出的请求继续走回执或对账。账号绑定、审计、回执和待核对记录继续可查。

**C2 验收** 模拟 Worker、只读连接器和发送执行器分别显示状态，停止 Worker 后失效报告不会一直显示就绪。跨角色绑定不可见，角色 ADMIN 不能更改部署配置。暂停账号后不能领取新发送许可。验证期间使用隔离夹具，控制台查询和状态核验产生的真实写请求为零。

## 5. API 缺口与实施顺序

| 阶段 | 优先复用 | 需要补齐的服务端能力 |
| --- | --- | --- |
| C1 | 本地会话、角色／身份／账号配置、控制命令、模拟审批、运行回放 | 会话的创建角色能力、当前角色自身权限投影、已启用模拟适配器选项、受控模拟触发与独立会话创建、角色级运行分页、按审批权限裁剪的结果投影。 |
| C2 | 角色级监控、Outbox 隔离与恢复、模拟对账、审计、本机连接器事件与单提案查询 | 本机连接器提案分页、运行与审计记录的最小关联索引、按进程的脱敏插件状态和按角色的绑定投影。 |
| C3 | 成员授权写入、记忆元数据与来源、授权、目标、反思、观点详情、计划、承诺、评测 | 成员列表、观点与联系人分页，以及授权表单所需的角色内受控选择项。 |

C1 按以下顺序实现并验收。

1. 拆分会话、角色上下文和审批组件，建立可直达的路由及统一请求层。
2. 交付角色、核心、身份和模拟账号表单，补齐创建角色权限与角色权限投影。
3. 接入模拟触发、运行分页及结果投影，贯通双用户审批到回执。
4. 用临时 PostgreSQL 和 Redis 完成一轮浏览器验收，再进入 C2。

所有新增查询在服务端按角色校验，分页与筛选由服务端处理。配置写入沿用版本头、幂等键和审计。遇到版本冲突时提示重新核对并保留用户输入。保留 API 对跨角色资源和权限不足的区分。控制台按权限展示按钮，API 负责最终授权。插件状态接口只返回声明元数据和脱敏诊断。

## 6. 交互与测试约定

每个角色有独立的平台账号池。管理员可先登记账号，再从同角色的身份关联未使用的账号。关联后的账号保持暂停，按原流程启用。账号注册和关联分别记录审计，未关联账号不会进入运行、审批和调度选择项。

「角色与身份」和「运行」使用平铺分区。时区选择支持搜索，身份可沿用角色时区，表单使用与 API 共享的校验规则。运行详情在宽屏与列表并排，在窄屏单独显示，返回时保留筛选和记录焦点。审批员没有直达链接时进入待办。待办中的模拟回复和连接器提案沿用列表与详情布局，审批前展示身份、账号、目标、受众和正文。记忆列表用身份、范围和创建时间区分记录，详情展示来源、修订和授权。插件页用一张表展示各进程的最近报告，按行展开版本与诊断。

运行配置、身份成长、角色成员、审计、指标及异常处置使用平铺分区。计划时区支持搜索，默认采用角色时区。每日计划以所选时区解释触发时间，单次提醒和承诺截止时间的输入标签标明浏览器时区。计划、承诺和成员权限变更表单在提交前复用 API 校验规则。

- 继续使用 Vue 3、Naive UI 和 pnpm。用布局、表格列和状态标识表达层级，每页突出一个主操作。列表使用名称，详情提供复制 ID。明确区分模拟、待执行、已确认与结果未知。
- 校验状态要覆盖加载、空数据、无权限、会话过期、版本冲突和失败重试。主要流程可键盘完成，窄屏保留目标、内容和审批操作。
- C1 重点覆盖角色切换时的异步数据隔离、最小权限导航、重复模拟触发和审批幂等。C2 重点覆盖越权查询、未知结果与重复恢复。C3 重点覆盖来源授权和成员权限边界。
- 每阶段更新[路线图](roadmap.md)，记录已上线页面、开放的权限、完成的验收与下一阶段范围。

## 7. 控制台界面重构

控制台骨架已接入 UnoCSS 与 Iconify 图标。顶部服务详情使用 Reka UI，已有工作区的组件随页面迁移逐步替换。四套主题支持浅色、深色和跟随系统，选择保存在当前浏览器。

工作台通过角色级监控与运行列表接口显示待处理事项和最近模拟运行。具备运行读取权限的用户可以访问工作台，审批员仍可从审批待办进入。侧栏将平台账号池和计划与承诺设为独立入口，继续沿用角色级直达链接。

角色与身份使用左右两栏。管理员可通过角色设置和身份名称打开编辑弹窗，在身份列表直接关联账号。平台账号池展示账号对应的角色与身份。同一身份只可新增一个未撤销的绑定，撤销后可关联另一个账号。

审批页分别展示模拟提案与 Newbi 公开回复。具备运行读取权限的用户可从模拟提案进入对应运行。运行记录将发起模拟、筛选、最近运行与异常处置分区，详情保留审批、审计和模拟对账入口。

浏览器使用隔离夹具核对了模拟批准、对账结案、运行详情重试、窄屏焦点恢复、Newbi 公开发布提示和审批员权限边界。独立 PostgreSQL 和 Redis 通过模拟回执、审批与 Newbi 协议夹具的集成测试。

插件中心为 Newbi、OpenAI、Anthropic Claude、Gemini 和 OpenAI 兼容服务分别提供插件卡。安装后可以启用，启用后在页面内打开配置。Newbi 单独列出读取与发送组件。配置 Agent API 后，角色管理员可从平台账号池登记账号，关联后核验连接并启用。

系统运行状况按控制面、模拟运行流程、Newbi 连接器和外部依赖展示。PostgreSQL 与 Redis 使用管理 API 的实时探测，进程使用限时报告。外部模型和 Newbi API 展示独立探测是否可用，配置存在、进程就绪和实际调用成功各有自己的状态来源。

系统运行状况将 Newbi 读取放在接收层，发送放在执行层，模型插件放在草稿层。插件停用后收起相关节点和配置入口。真实外部服务调用和发布源升级按各自的验收范围交付。

### 插件升级预览

发布维护者从目标版本的 Rica 源码生成清单，构建和部署沿用现有流程。下面的命令使用示例发布地址，发布时换成固定版本的实际 HTTPS 说明页。

```sh
pnpm exec tsx scripts/plugin-release-manifest.ts https://example.com/releases/v0.2.0 > plugin-release.json
```

部署维护者核对清单与目标发布，将文件放到仅部署流程可写的位置，并给管理 API 设置 `RICA_PLUGIN_RELEASE_MANIFEST` 的绝对路径。刷新插件时重新读取文件。未配置、清单不可用、以及清单中没有组件变更分别显示。预览逐组件比较部署版本、目标版本和契约，Newbi 任一组件缺失、契约变化或降级都会标出。

部署维护者从发布说明取得目标版本并协调部署 API、Worker 和执行进程。上线前核对 Newbi 在途及未知发送，按原执行版本和原幂等键完成恢复，或由管理员按现有流程结案。控制台预览无部署写权限。

### 跨身份计划

角色管理员可在计划列表新建、编辑、暂停及恢复计划。勾选已关联账号的身份并逐一填写执行事项。列表直接显示来源、各参与身份、平台、事项和最近模拟运行。换绑账号后需在计划中确认新的参与账号。

每个模拟账号使用独立会话和定时任务，到点沿用现有模拟上下文准备、静默时段及去重规则。真实平台可参与同一计划，事项由人工跟进。

### 承诺事项与协作

角色管理员可在承诺列表或运行详情选择尚未登记的已确认模拟回执，填写承诺事项、截止时间和可选的协作身份。列表直接显示负责人、对象、协作身份及平台。负责身份、对象和提醒账号绑定原回执。编辑事项、协作或标题保留已有提醒，延后截止时间才会重新安排提醒。协作关系用于跟进记录。

已配置托管模型时，公开模拟回复可附带一项计划或承诺。审批详情同时显示回复及后续事项。回执确认后，仍在有效期限内的事项自动登记到「计划与承诺」，并标注 AI 来源。生成时沿用当前模拟身份与账号，管理员可补充协作身份。
