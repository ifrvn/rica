# Rica 控制台使用及维护

控制台按当前角色展示数据和可用操作。宿主 API 负责最终授权。完整请求和角色权限见[管理 API](management-api.md)。

| 入口 | 日常操作 |
| --- | --- |
| 工作台和运行记录 | 看待处理事项和最近运行，从角色上下文发起模拟，按筛选打开运行回放、审批、审计和对账。 |
| 角色与身份、平台账号池 | 配置角色和身份，先登记账号再关联到身份。关联后账号默认暂停，管理员核验后启用。 |
| 审批 | 查看模拟提案和 Newbi 公开回复。审批详情显示身份、账号、目标、正文和审核理由。模拟批准后由独立执行器处理，Newbi 由管理员显式触发单次发送。 |
| 计划与承诺 | 选择已关联账号的身份参与计划，为模拟参与项各自调度。承诺可由已确认回执登记。计划、提醒及恢复规则见[模拟运行](simulation.md#计划调度)。 |
| 记忆与身份成长 | 浏览授权范围内的记忆、来源和修订，管理共享、撤销和纠错，并查询身份的目标、反思与观点。 |
| 成员与审计 | 管理角色成员，保留至少一名管理员。按角色查询操作审计。 |

## 插件配置与运行状态

还没有角色时，部署管理员登录后可新建角色，也可直接打开插件中心、系统运行状况和外部模型统计。账号绑定、审批和模拟运行需要先选择角色。

部署操作者通过插件中心登记、启用、配置和停用随 Rica 交付的插件。角色管理员在各角色内管理账号绑定。第三方包通过部署清单安装，可用 [SDK 控制台贡献](plugin-development/08-package-sdk.md#控制台贡献)展示角色内的卡片、摘要和账号登记字段。

系统运行状况分别展示配置状态、进程报告和外部调用结果。PostgreSQL 和 Redis 来自 API 实时探测。常驻进程约每 5 秒报告一次，20 秒没有报告时显示未知。Newbi 读取节点显示当前角色有效账号和最近读取情况，发送节点显示确认回执和待对账结果。

外部模型的连接测试使用已保存并启用的配置。测试通过后，可在已启用的模拟账号上试写，并在运行详情核对 Worker 实际使用的模型。发布预览、组件版本和升级步骤集中在[插件发布指南](plugin-development/06-verification-release.md#发布版本与升级预览)。

## 维护与验收

控制台使用 Vue、Reka UI、UnoCSS 和 Iconify。主题、基础控件与请求工具由 [console-shared](../packages/console-shared/package.json) 提供，业务组件按功能留在各自包内；内置插件的装配见[控制台开发接口](plugin-development/05-console.md)。主题支持浅色、深色和跟随系统，偏好保存在当前浏览器。

发起和审批外部动作时，界面应展示实际账号、目标、受众与内容。设置写入使用版本校验，冲突时保留用户输入。角色切换后丢弃上一角色迟到的响应。运行详情和审批入口支持角色级直达链接，返回列表时保留筛选和焦点。

验证受影响的页面时覆盖 320px 窄屏、键盘、主题、空态、无权限和请求失败。关键写入使用协议夹具，核对幂等、提案人与审批人分离以及回执。公共 UI 的改动运行 `pnpm run typecheck` 和 `pnpm run build`。项目通用约定见 [AGENTS.md](../AGENTS.md)。
